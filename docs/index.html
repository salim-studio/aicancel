Quick start

Run as administrator. Finish pending Windows updates first.

REM Interactive menu (recommended)
aicancel.bat

REM Full silent removal with backup
aicancel.bat -all

REM Preview only — nothing is removed
aicancel.bat -scan

REM Revert everything
aicancel.bat -revert
# Full silent run with backup + logging
powershell -NoProfile -ExecutionPolicy Bypass -File .\aicancel.ps1 -NonInteractive -All -Backup -EnableLog

# Selected modules only
powershell -NoProfile -ExecutionPolicy Bypass -File .\aicancel.ps1 -NonInteractive -Options DisableReg,RemoveAppx,RemoveCBS

# Scan only
powershell -NoProfile -ExecutionPolicy Bypass -File .\aicancel.ps1 -ScanOnly -NonInteractive -All

What it removes

12 modules. One registry batch, one CBS scan, one TrustedInstaller pass — no dead waits.

Registry lockdown

All WindowsAI / WindowsCopilot policies, AI consent stores, background access, voice activation, telemetry, taskbar button, Click to Do.

Edge AI

EdgeAI
Office AI

Every Copilot / Recall rule in IntegratedServicesRegionPolicySet.json set to disabled.

RemoveCBS

Watchdog

Safety first

Powerful tools deserve guardrails. aicancel ships with four.

Scan before you remove

-ScanOnly previews everything that would change. Nothing is touched.

Restore point

Created automatically on full runs before anything changes.

Backup + revert

-Backup saves policies; -Revert rolls the system back.

Update check

Refuses to run while a Windows update is installing or a reboot is pending.

Note: test in a virtual machine first if unsure. Some antiviruses flag debloat tools as suspicious (false positive) — the script is plain-text PowerShell, read it before running. Home editions ignore some Group Policy keys by Windows design; Pro / Enterprise / Education give full coverage.
